## 新增

- 用户资料页新增「共同群发言」，列出对方在你们共同所在群里的近期发言（Nagram 设置 › 其他 › 资料页 › 显示共同群发言入口）。
- 新增「超出上限时本地置顶」（Nagram 设置 › 会话 › 置顶会话）：置顶数量超过 Telegram 的上限后，多出的会话只在本机置顶。
- 新增「分组标签放在底部」（Nagram 设置 › 会话 › 分组）：会话列表的分组标签移到底栏上方。
- 新增「滑过最后一个分组回到第一个」（Nagram 设置 › 会话 › 分组）：在最后一个分组继续左滑会回到第一个分组；未开通 Premium 时不再弹出分组上限提示。
- 新增「隐藏新建对话按钮」（Nagram 设置 › 会话 › 会话列表）。
- 新增「视频控制按钮放在进度条下方」和「视频快进步长」（Nagram 设置 › 会话 › 手势）：播放视频时不再在画面中央显示大圆按钮，快进、快退步长可选 5 / 10 / 15 / 30 / 60 秒。
- 新增「转发时默认隐藏发送者」（Nagram 设置 › 消息 › 发送）：转发时一开始就隐藏发送者，单次转发仍可在预览里改回。
- 新增「群简介中的网址可点击」（Nagram 设置 › 消息 › 消息显示）：群简介里的外部网址也能点开。
- 新增「显示转发次数」（Nagram 设置 › 消息 › 频道）：频道消息在浏览数旁显示转发次数。
- 论坛群的话题页也显示聊天顶部工具栏。
- 群和频道的「加入请求」中，长按申请可「拒绝并封禁」。
- 消息菜单新增「私下回复」：在群里长按别人的消息，打开与对方的私聊并引用这条消息。默认不显示，可在 Nagram 设置 › 消息 › 消息菜单 › 消息菜单管理中打开。
- 长按群或频道里的消息可「添加到消息过滤」：自动填入这条消息，可删减成关键字。规则可以设置为只在指定聊天中生效。
- 新增「被过滤的消息自动已读」（Nagram 设置 › 消息 › 过滤）：一个聊天的未读消息全部被过滤规则隐藏时，自动把它标为已读，并同步到其他设备。
- 「显示用户 ID」和「显示数据中心」（Nagram 设置 › 其他 › 资料页）也作用于群组和频道：资料页显示群组或频道的 ID（与 Bot API 相同的 -100… 格式）和数据中心，长按可复制。

## 变更

- 同步 Telegram 官方 13.2 版本的代码，主要包括：
  - iPad 和话题群可以在聊天旁显示会话侧边列表。
  - 通话中「添加成员」可以一次选择多人；对方的隐私设置不允许直接邀请时，会改为发送通话链接。
  - 富文本消息、钱包和 iPad 分屏布局的多项改进。

## 修复

- 修复在设置中搜索并打开结果、返回后关闭搜索，底栏背景变透明的问题。
- 修复只包含「最近」的分组移到第一位并保存后消失，放在最后也会在一段时间后或在其他设备登录后消失的问题。这类分组的会话来自本机的最近记录，因此分组只保存在本机，其他设备上不会显示。
- 修复未识别型号的 iPad 首次打开时状态栏高度不对的问题。
- 修复在不支持画中画的设备上打开视频会闪退的问题。
