## 新增

- 用户资料页新增「共同群发言」，列出对方在共同群里的近期发言（Nagram 设置 › 其他 › 资料页）。
- 新增「超出上限时本地置顶」（Nagram 设置 › 会话 › 置顶会话）：超过 Telegram 上限的置顶只保存在本机。
- 新增「分组标签放在底部」（Nagram 设置 › 会话 › 分组）：会话列表的分组标签移到底栏上方。
- 新增「滑过最后一个分组回到第一个」（Nagram 设置 › 会话 › 分组）；未开通 Premium 时不再弹出分组上限提示。
- 新增「隐藏新建对话按钮」（Nagram 设置 › 会话 › 会话列表）。
- 新增「视频控制按钮放在进度条下方」和「视频快进步长」（Nagram 设置 › 会话 › 手势）：画面中央不再显示大圆按钮，快进快退步长可选 5–60 秒。
- 新增「转发时默认隐藏发送者」（Nagram 设置 › 消息 › 发送），单次转发仍可在预览里改回。
- 新增「群简介中的网址可点击」（Nagram 设置 › 消息 › 消息显示）。
- 新增「显示转发次数」（Nagram 设置 › 消息 › 频道）：频道消息在浏览数旁显示转发次数。
- 论坛群的话题页也显示聊天顶部工具栏。
- 群和频道的「加入请求」中，长按申请可「拒绝并封禁」。
- 消息菜单新增「私下回复」：长按群里别人的消息，转到与对方的私聊并引用它。默认不显示，可在 Nagram 设置 › 消息 › 消息菜单 › 消息菜单管理中打开。
- 长按群或频道里的消息可「添加到消息过滤」，规则可设为只在指定聊天中生效。
- 新增「被过滤的消息自动已读」（Nagram 设置 › 消息 › 过滤）：未读消息全部被过滤时自动标为已读，并同步到其他设备。
- 「显示用户 ID」和「显示数据中心」也作用于群组和频道（ID 为 Bot API 的 -100… 格式），长按可复制。
- 新增「保存拍摄的照片和视频」（设置 › 数据与存储 › 其他）：关闭后，App 内相机拍摄的照片和视频不再存入系统相册。
- 新增「高刷新率滚动」（Nagram 设置 › 界面 › 外观）：拖动列表时保持最高刷新率，更流畅但更耗电。默认关闭。

## 变更

- 同步 Telegram 官方 13.2 版本的代码，主要包括：
  - iPad 和话题群可以在聊天旁显示会话侧边列表。
  - 通话中「添加成员」可以一次选择多人；对方的隐私设置不允许直接邀请时，会改为发送通话链接。
  - 富文本消息、钱包和 iPad 分屏布局的多项改进。

## 修复

- 修复在设置中搜索并打开结果、返回后关闭搜索，底栏背景变透明的问题。
- 修复只包含「最近」的分组保存后消失的问题。这类分组只保存在本机，其他设备上不会显示。
- 修复未识别型号的 iPad 首次打开时状态栏高度不对的问题。
- 修复在不支持画中画的设备上打开视频会闪退的问题。
- 修复长按底栏的头像有时无法打开账号切换的问题。
- 修复开启「强制复制」后，受保护群和频道的消息菜单里没有「复读」的问题。
- 修复聊天最新的几条消息都被过滤规则隐藏时，聊天一直显示未读的问题。
- 修复消息过滤规则的正则内容很长时，输入框无法滚动的问题。
- iPad mini（A20 Pro）上，修复竖屏时屏幕上下出现黑边、App 没有铺满屏幕的问题。
- 修复 iPad 连续旋转后，状态栏的电池和信号图标停在屏幕中间或消失的问题。
- 修复 iPad 上中文或日文输入法的候选栏挡住文本格式栏和会话列表的问题；候选栏收到角落时不再留白。
